# HomeFit – Personalized Home Fitness Tracker

A tropical-themed home workout app prototype. It plans workouts, guides you through them live, and tracks your consistency and recovery.

**Live demo:** https://kani-05.github.io/HomeFit/

<!-- Add a screenshot: ![HomeFit tracker](screenshot.png) -->

## Features
- **Home screen:** today's workout (Chest + Triceps Foundation), weekly consistency, muscle-recovery readiness, and a weekly schedule.
- **Live workout runner:** step through sets, track reps, use the rest timer (+15s / +30s), skip an exercise, or swap in an alternative.
- **Workout builder:** choose a duration (10 to 45 minutes) and equipment (bodyweight or dumbbells) to start a custom routine.
- **Exercise library:** searchable list of 60+ movements.
- **Coach chat:** quick prompts such as "What should I train today?" and "I only have 15 minutes". (The replies are scripted for this demo; no live AI model is connected.)
- **Analytics:** personal records shelf and a workout history calendar.
- **Light/dark theme** and celebration confetti after workouts.

## Built with
HTML, Tailwind CSS, vanilla JavaScript, and a confetti library, in a single file. Built with Google Antigravity (AI-assisted development).

## Run locally
Download `index.html` and open it in a browser. An internet connection is needed for Tailwind and fonts.

## Note
This is a front-end prototype. Workout data is sample data and is not saved to a server.
